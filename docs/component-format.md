# Формат пакета

`components/<id>/manifest.json` — машиночитаемая точка входа. ID совпадает с именем папки и состоит из строчных латинских букв, цифр и дефисов. Версия — X.Y.Z.

- `status`: draft / experimental / validated.
- `compatibility`: product, version, python. Пока runtime не проверен, используйте unverified.
- `units`: length=mm, time=s, speed=mm/s.
- `model`: путь относительно пакета либо null только для draft.
- `scripts`, `test_scenarios`: списки существующих файлов относительно пакета.
- `dependencies`: список объектов `{"id": "box", "version": "0.1.0"}`. Версия должна совпадать с текущей версией пакета в checkout. Для воспроизводимости старых версий используйте commit/tag всего репозитория.
- `evidence`: список путей к отчётам относительно **корня репозитория**, например `results/stu-0.1.0-smoke.md`.

Пути используют `/`, абсолютные пути и выход за пределы разрешённой папки запрещены. Проверка подтверждает наличие файлов, метаданные, зависимости и отсутствие циклов. Она не оценивает правдивость отчёта и не запускает модель. Статус validated требует ручного ревью доказательств.

Манифест шаблона не является зарегистрированным компонентом. В начальном каталоге намеренно нет фиктивных готовых моделей.
